# AI社長

SNS（X / TikTok）からの流入を受け止める、Lit.link代わりの自作リンクトビオ型ランディングページ。React + TypeScript + Vite + Tailwind CSS製。

## できること

- プロフィール／SNSリンク一覧
- 商品カード（入口商品・スポット案件・月額サブスク）を「フロント」「バックエンド」「継続サポート」に分けて表示
- 決済リンク（Stripeの支払いリンクなど）を貼るだけで「申し込む」ボタンが有効化される仕組み

## 中身を編集する

内容はすべて `src/data/site.ts` にまとまっています。プロフィール文言、SNSリンク、商品（名前・説明・価格・決済URL）はこのファイルを書き換えるだけで反映されます。コード側（コンポーネント）を触る必要はありません。

決済リンクが未設定（`"#"` のまま）の商品は自動的に「準備中」の非活性ボタンになります。Stripeなどで決済リンクを発行したら `paymentUrl` に貼ってください。

## 開発

```bash
npm install
npm run dev      # 開発サーバー起動
npm run build    # 本番ビルド（dist/ に出力）
npm run lint      # Lint
```

## Claude Code on the web の環境設定について

このリポジトリでセッションを作る場合の設定例:

- **ネットワークアクセス**: `Trusted`（npm registryへのアクセスに必要）
- **環境変数**: 現状は不要（空欄でOK）。将来Stripe等の外部APIキーを使う場合も、キー自体はここではなく「シークレット」機能に入れること
- **セットアップスクリプト**:
  ```bash
  #!/bin/bash
  npm install
  ```
